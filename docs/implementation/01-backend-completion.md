# 01. Backend Completion

## Tujuan
Menyelesaikan modul backend yang masih belum lengkap dan memastikan endpoint utama siap dipakai oleh frontend.

## Scope Kerja
- Tingkatkan modul mesin cuci dengan CRUD dan perbaikan query ketersediaan.
- Tambah fitur forgot password pada modul auth.
- Perluas modul transaksi dengan confirm payment, daily recap, dan generate PDF.
- Tambah endpoint report yang mendukung performa shift dan export data.

## Checklist
- [ ] Implementasi CRUD mesin cuci
- [ ] Perbaiki logika pencarian mesin tersedia berdasarkan tanggal dan shift
- [ ] Tambah endpoint forgot password
- [ ] Tambah endpoint confirm payment
- [ ] Tambah endpoint daily recap
- [ ] Tambah endpoint generate PDF struk
- [ ] Tambah endpoint report performa shift dan export

## Deliverables
- Backend API yang stabil untuk modul utama
- Penyesuaian route, controller, service, dan repository
- Dokumentasi endpoint terbaru

## Catatan
- Prioritaskan modul yang menjadi blocker integrasi frontend.
- Pastikan response format konsisten dengan standar API proyek.
