# 02. Database & Seed Data

## Tujuan
Melengkapi data basis data agar aplikasi dapat diuji secara realistis dan konsisten.

## Scope Kerja
- Lengkapi seed data untuk customer, karyawan, owner, layanan, mesin, booking, transaksi, dan notifikasi.
- Pastikan data sesuai dengan alur bisnis laundry hybrid.
- Periksa constraint dan relasi antar tabel.

## Checklist
- [ ] Tambah seed data user awal
- [ ] Tambah seed data layanan laundry
- [ ] Tambah seed data mesin cuci dan pengering
- [ ] Tambah seed data booking contoh
- [ ] Tambah seed data transaksi contoh
- [ ] Tambah seed data notifikasi dan shift

## Deliverables
- Database yang siap dipakai untuk development dan demo
- Data contoh yang konsisten untuk seluruh role pengguna

## Catatan
- Seed data harus memudahkan pengujian login, booking, dan pembayaran.
