# 04. Frontend Mobile - API Integration

## Tujuan
Menghubungkan aplikasi mobile customer ke backend agar flow booking dan tracking berjalan nyata.

## Scope Kerja
- Hubungkan layar login, register, dan forgot password ke API.
- Integrasikan booking laundry dan pemilihan mesin dengan endpoint backend.
- Perbaiki route mismatch dan sinkronisasi data dengan server.

## Checklist
- [ ] Integrasi auth mobile
- [ ] Integrasi booking layanan kiloan dan koin
- [ ] Integrasi tracking status pesanan
- [ ] Integrasi riwayat pemesanan
- [ ] Perbaiki route dan navigasi yang tidak sesuai

## Deliverables
- Aplikasi mobile customer yang terhubung ke backend
- Alur booking dan tracking yang berjalan nyata

## Catatan
- Fokus pada kebutuhan customer sebagai pengguna utama mobile.
