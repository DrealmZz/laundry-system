# 03. Frontend Web - API Integration

## Tujuan
Menghubungkan antarmuka web dengan backend agar tidak lagi bergantung pada data lokal atau hardcoded login.

## Scope Kerja
- Ganti data dummy dengan API backend untuk auth, booking, transaksi, dan laporan.
- Integrasikan flow login, register, dan dashboard kasir/admin/owner.
- Hubungkan halaman transaksi, laporan, dan manajemen data ke endpoint yang benar.

## Checklist
- [ ] Integrasi login dan session auth
- [ ] Integrasi CRUD layanan dan user management
- [ ] Integrasi booking dan status pesanan
- [ ] Integrasi transaksi dan pembayaran
- [ ] Integrasi halaman laporan dan rekap
- [ ] Perbaiki error handling dan loading state

## Deliverables
- Frontend web yang terhubung penuh ke backend
- Pengalaman pengguna yang konsisten dengan state server

## Catatan
- Fokus pada role kasir, admin, dan owner terlebih dahulu.
