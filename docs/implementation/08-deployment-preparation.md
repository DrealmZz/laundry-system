# 08. Deployment Preparation

## Tujuan
Mempersiapkan proyek agar siap di-deploy ke lingkungan staging atau produksi.

## Scope Kerja
- Siapkan konfigurasi environment untuk backend, frontend, dan database.
- Verifikasi dependency dan command build.
- Pastikan aplikasi dapat berjalan pada lingkungan yang benar.

## Checklist
- [ ] Siapkan file environment backend
- [ ] Siapkan file environment frontend
- [ ] Verifikasi build production
- [ ] Siapkan database production atau staging
- [ ] Siapkan langkah deployment dan rollback

## Deliverables
- Rencana deployment yang jelas
- Environment yang siap digunakan

## Catatan
- Jangan lupa mencatat service, port, dan secret yang diperlukan.
