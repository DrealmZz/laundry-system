# 06. Testing

## Tujuan
Memastikan sistem berjalan sesuai kebutuhan dan tidak terjadi regresi saat fitur baru ditambahkan.

## Scope Kerja
- Lakukan pengujian backend API.
- Uji integrasi frontend dengan backend.
- Cek alur utama seperti login, booking, transaksi, dan laporan.

## Checklist
- [ ] Uji endpoint auth
- [ ] Uji endpoint booking dan transaksi
- [ ] Uji endpoint mesin dan report
- [ ] Uji alur mobile customer
- [ ] Uji alur web kasir/admin/owner
- [ ] Dokumentasikan bug dan perbaikan

## Deliverables
- Hasil pengujian yang terdokumentasi
- Daftar bug yang sudah diperbaiki atau ditunda

## Catatan
- Pengujian harus mencakup skenario sukses dan skenario error.
